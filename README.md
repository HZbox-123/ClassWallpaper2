# ClassWallpaper 班级自动壁纸管理系统 · 部署文档

> 面向部署者（老师 / 机房管理员）的安装、配置与维护指南。
> 适用环境：Windows 10 64 位，班级电脑（建议安装 Deep Freeze 仅保护 C 盘）。

---

## 1. 系统概述

ClassWallpaper 自动管理班级电脑桌面壁纸：为每位同学准备一张以**姓名命名**的壁纸图片，按**排班计划**自动轮换（默认每周三更换，规则可自定义）。

- **自动换壁纸**：开机静默自启 → 启动时检查 → 运行中每 15 分钟检查一次 → 排班日自动切换，错过日期自动补执行
- **壁纸缺失兜底**：某同学未上传壁纸时自动回退「默认.jpg」，并每天首次气泡提醒
- **单实例运行**：重复打开只会激活已有窗口，不会多开托盘/重复执行
- **静默后台**：开机自启不弹界面，只驻留托盘；手动打开才显示界面
- **数据安全**：配置、壁纸、日志默认保存在 `D:\ClassWallpaper`，**不受 Deep Freeze 还原影响**；无 D 盘或自定义安装时自动适配（见第 3 节）

## 2. 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 64 位 |
| 磁盘 | 推荐 D 盘（程序与数据装在 D 盘）；**无 D 盘（单盘电脑）也可运行**，数据自动放程序目录 |

## 3. 安装步骤

1. 将 `ClassWallpaper.exe` 复制到目标位置（推荐 `D:\ClassWallpaper\`）。
2. 双击启动。首次运行自动创建 `Config`、`Wallpapers`、`Logs` 目录和默认配置。
3. （推荐）**在解冻状态下**完成第 4~9 节配置，然后重新冻结。

### 3.1 自定义安装位置（可选）

程序按以下顺序自动选择数据目录，取第一个可用的：

| 优先级 | 方式 | 说明 |
|---|---|---|
| 1 | 环境变量 `CLASSWALLPAPER_ROOT` | 如 `E:\班级壁纸数据`，脚本/统一部署用 |
| 2 | exe 旁的 `ClassWallpaper.root` 文件 | 文件内容写一行目录路径，**自定义安装推荐** |
| 3 | `D:\ClassWallpaper` | 班级电脑部署约定（默认） |
| 4 | 程序所在目录 | 单盘电脑兜底 |

**例：想装到 E 盘**
在 exe 旁边新建 `ClassWallpaper.root`，内容为 `E:\班级壁纸数据`，保存后启动即可——所有数据都会建在该目录下。

### 3.2 目录结构

```
数据根目录\
├── Config\                   # 配置文件（settings / users / schedule）
│   ├── settings.json         # 应用设置（日志天数、壁纸目录、检查间隔等）
│   ├── users.json            # 班级人员名单
│   └── schedule.json         # 排班计划
├── Wallpapers\               # 壁纸图片（姓名.jpg；默认.jpg 做兜底）
└── Logs\                     # 运行日志（按天滚动，保留 30 天）
```

## 4. 首次配置流程（约 15 分钟）

### 4.1 导入人员名单（人员管理页）

1. 打开「**人员管理**」页。
2. 点击「**从 Excel 导入...**」，选择班级名单 `.xlsx` 文件。
3. Excel 格式约定：

   | A 列 | B 列 |
   |---|---|
   | 姓名（如：张三） | 排序号（如：1，可留空） |

   第一行可以是表头（"姓名 / 排序"），也可直接是数据。支持手动添加 / 删除 / 上移下移 / 多选批量删除。

### 4.2 准备壁纸图片（壁纸管理页）

1. 将每位同学的壁纸图片放入壁纸目录（默认 `...\Wallpapers`），文件名为 **`姓名.jpg`**（如 `张三.jpg`）。
2. 支持格式：`.jpg / .jpeg / .png / .bmp`。
3. **务必准备一张 `默认.jpg`**：某人未上传壁纸时自动回退使用，避免桌面空白。
4. 回到「**壁纸管理**」页点「**刷新**」查看绑定情况：绿色「已绑定」/ 红色「缺失」；选中后可「应用到桌面」预览。
   - 同名图片替换内容后：刷新即显示新图，应用到桌面立即生效（程序自动清除系统壁纸缓存）。

### 4.3 生成排班计划（排班计划页）

1. 打开「**排班计划**」页。
2. 设置规则：勾选**排班星期**（如只勾「星期三」）、设置**起止日期**、添加**节假日**（生成时跳过）。
3. 点击「**生成计划**」：按人员排序顺序循环分配，同一个人一周内最多轮值一次；**生成后立即应用今日壁纸**。
4. 可在列表双击单元格手动调整（改日期 / 人员），点「保存修改」。
5. 到「**概览**」页确认「今日轮值」和「待办提醒」无误。

### 4.4 设置与开机自启（设置页）

1. 打开「**设置**」页。
2. 点击「**开启开机自启**」（**务必在解冻状态下操作**，见第 5 节）。
   - 开启后自启为**静默模式**：开机自动后台运行，不弹界面。
3. 按需调整：
   - **日志保留天数**：默认 30 天
   - **壁纸填充方式**：适应 / 拉伸 / 居中 / 平铺
   - **启动时显示主窗口**：手动打开程序时是否显示界面（开机自启始终静默，不受此开关影响）
   - **换壁纸检查间隔**：默认 15 分钟（0.25 小时）
   - **壁纸目录**：默认 `...\Wallpapers`，可自定义
   - **数据目录**：当前实际数据根目录（只读显示，自定义安装见 3.1）
4. 点击「**保存设置**」。

### 4.5 验证

- 桌面壁纸已切换为今日轮值同学
- 重启电脑 → 程序**静默自动启动**（只托盘图标，无窗口）→ 壁纸按排班切换
- 双击 exe / 点托盘图标 → 界面正常打开

## 5. 冰点还原（Deep Freeze）策略

| 项目 | 存放位置 | 是否受还原影响 |
|---|---|---|
| 程序本体 | D 盘（或自定义目录） | 不受影响 |
| 配置 / 壁纸 / 日志 | 数据根目录（默认 D 盘） | 不受影响 |
| 开机自启注册表 | C 盘 | **会被还原** |

**关键操作：开机自启必须在"解冻"状态下开启一次**，让冰点把注册表项写入快照，之后冻结状态下保持自启（含静默 `-silent` 参数）。

```
解冻 → 程序内开启自启（写入静默参数）→ 冻结 → 日常使用（数据持续写入 D 盘）
```

> 说明：程序设置壁纸时会写入 C 盘壁纸缓存（TranscodedWallpaper），冻结状态下会被还原；程序每次换壁纸前会自动清除该缓存，因此无任何影响。

## 6. 日常使用

- **托盘图标**（右下角）：
  - 左键单击 / 双击：打开主界面
  - 右键菜单：打开 / 立即换壁纸 / 打开壁纸目录 / 退出
- **关闭窗口** = 最小化到托盘，程序继续后台运行
- **单实例**：重复打开 exe 只激活已有窗口，不会重复启动
- **自动换壁纸**：启动时 + 每 15 分钟 + 排班日自动切换；错过日期补执行（不会重复）
- **壁纸缺失处理**：自动回退「默认.jpg」；无默认则保持当前壁纸；每天首次气泡提醒「XX 未上传壁纸」
- **换照片**：直接替换 `Wallpapers` 里的图片（同名即可），壁纸页点「刷新」→ 应用到桌面立即生效

## 7. 配置文件说明

| 文件 | 内容 | 建议 |
|---|---|---|
| `Config\settings.json` | 日志天数、壁纸目录、填充方式、显示窗口、检查间隔 | 用「设置」页修改，勿手改 |
| `Config\users.json` | 人员名单（姓名 + 排序号） | 用「人员管理」页修改 |
| `Config\schedule.json` | 排班计划（日期 + 人员 + 生成参数） | 用「排班计划」页修改 |
| `Logs\` | 运行日志 | 出问题时查看，按天滚动自动清理 |

## 8. 常见问题（FAQ）

**Q1：换了图片（同名）后点「应用到桌面」没反应？**
已内置修复：每次设置前自动清除系统壁纸缓存，同名替换后立即生效。若仍无反应，先点「刷新」释放文件占用再试。

**Q2：壁纸管理页预览不更新？**
点「刷新」即可——预览使用文件流加载，每次重新读取磁盘内容。

**Q3：到点了没有自动换壁纸？**
依次检查：① 设置页「换壁纸检查间隔」（建议 0.25 小时）② 排班是否已生成且包含今天 ③ 今天是否为勾选的星期 / 是否撞上节假日 ④ 今日轮值同学的壁纸是否存在。查看 `Logs\` 日志可定位原因。

**Q4：开机没有自动启动？**
冰点还原环境需在**解冻状态**下开启自启；确认「设置」页按钮显示「关闭开机自启」（已开启）。

**Q5：开机自动弹界面，不想要？**
自启应带 `-silent` 静默参数。若弹界面：① 确认使用的是最新版 exe ② 设置页把自启**关掉再重新开启**一次（刷新注册表值），或手动检查注册表：
```
HKCU\...\Run 的 ClassWallpaper 值应形如："C:\...\ClassWallpaper.exe" -silent
```

**Q6：单盘电脑（没有 D 盘）能跑吗？**
能。自动使用程序所在目录存放数据；也可用 `ClassWallpaper.root` 文件指定任意位置（见 3.1）。

**Q7：支持什么图片格式？**
`.jpg / .jpeg / .png / .bmp`，文件名必须与人员姓名完全一致（如 `张三.jpg`）。

**Q8：怎么备份？**
复制数据根目录下的 `Config` 和 `Wallpapers` 即可完整备份配置与壁纸。

**Q9：冻结状态下能正常换壁纸吗？**
能。程序与数据都在数据根目录（D 盘），壁纸写入 C 盘的系统缓存程序会自动清理，无需解冻。

## 9. 更新与卸载

**更新**：
1. 解冻（Deep Freeze）
2. 退出程序（托盘 → 退出）
3. 用新版本替换 exe
4. 重新冻结（配置/壁纸在数据目录不丢）

**卸载**：
1. 程序内关闭「开机自启」
2. 托盘 → 退出
3. 删除 exe 和数据目录（含 `ClassWallpaper.root` 若创建过）

## 10. 开发与构建（技术人员）

- 开发环境：.NET 8 SDK（`D:\dotnet`），Visual Studio / VS Code
- 构建：`dotnet build D:\ClassWallpaper\ClassWallpaper.sln`
- 发布单文件 exe（免装 .NET 运行时，约 71 MB）：
  ```
  dotnet publish D:\ClassWallpaper\src\ClassWallpaper\ClassWallpaper.csproj -c Release -r win-x64 -p:PublishSelfContained=true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
  ```
  产物：`bin\Release\net8.0-windows\win-x64\publish\ClassWallpaper.exe`
- 自动化测试：`dotnet run --project D:\ClassWallpaper\tests\ConfigTest`（30+ 用例）
